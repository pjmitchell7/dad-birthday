# Dad's Day

A small personal birthday adventure built as a portable static website, using local Three.js modules and original procedural 3D assets.

## Experience

- Dad comes out of the front door, waves, and thinks about the choices.
- Movie night: yellow tank top, 3D glasses, popcorn and remote; the doorway opens into a short movie-night birthday scene.
- Gym: black shirt, navy sweatpants, gray sneakers, sunglasses and gym bag; tap the silver coupe to walk over and drive away.
- Drive: vacation shirt, fedora and sunglasses; tap the blue convertible to drive away.
- Touch-friendly portrait layout, landscape layout, keyboard-accessible choices, fullscreen where supported, and reduced-motion handling.

## Local preview

Run `npm run serve`, then open `http://localhost:4173`. No build step or API key is needed. All required 3D assets are included; the optional web fonts fall back to system fonts offline.

## Current scope

The car and person meshes are simplified original interpretations. This is an early stylized prototype, not a photorealistic likeness or a Blender/Unreal production asset. There are no full gym or driving levels. No favorite songs, exact birthday age, name, or final personal message have been supplied. Portrait works without requiring device orientation lock. No reference photos, addresses or license plates are included in the published assets.

The static output is in `dist`. `assets/THREE-LICENSE.txt` contains the Three.js license. The private preview requires its owner's access; recipient sharing must be configured separately.
